# 格式与验收

## 自动核验

- 来源 SHA256、相对引用、PNG 尺寸、显式矩形与覆盖；原图不改写，裁切 RGBA 原样保留。
- 图块/组/来源 Id、稀疏编号空洞、GID 区间和真实引用，图层 CSV 数量及有限地图像素预算。
- Wang 八位置、颜色范围、类型、预期连接及缺项；每个 terrain 格都有真实规则，每个动画帧实际存在。
- 图章和组合尺寸、成员、画布和接地点；单次/状态不写为 TSX 循环动画，透明终帧保留。
- build 从最终 catalog.tmx 读取图层、对象和图片再生成预览，检测不支持的格式并报错，不偷偷加载 Tiled。
- check 在内存重新编译并比较描述、来源、文件内容和生成登记；只读不修复。源变化、引用缺失或手改产物均报错。
- 密集展示板的对象说明放在对象自定义属性（`名称`）中，不写入 Tiled 的对象 `name` 标签；离线预览不会显示编辑器标签，必须单独核对 XML，避免总览缩放时文字遮挡素材。

工具不理解艺术语义。合法 XML、零错误或连接数量充足不能证明接口、帧序、美术或 GUI 刷子正确。

## AI 必须实际检查

查看坐标原图和最后 TMX 预览，核对原生网格、用途筛选、地图素材覆盖、完整图章、结构组与变体。核查每个地形族、凸凹角/窄路/洞口/擦除所需形状，明确受限边界；不能以某个静态示例好看推断所有形状都支持。

看环境动画实际播放或逐帧图，检查完整主体、阴影、透明终帧无残影；状态集不按未知时序串播。查看组合实际端点、接口、接地及遮挡，不把单体摆放算组合。

## 分层报告

展示板按结构组生成真实 Tiled group，组内含普通格、完整图章、动画帧、规则样例与独立组合成员。分区采用确定性二维排布；核对分区边界不重叠、原尺寸对象没有裁切、所有图层/对象 Id 唯一。原图目录默认隐藏，逐张开关对照；空白练习层保持全零。大型素材包也保留单入口，不靠提高像素预算绕过检查。

| 验证 | 结果记录 |
| --- | --- |
| 文件、引用、源像素、静态 Wang | build/check 给出；失败不得绕过 |
| 离线画面、组合、实际帧 | AI 查看后如实记录，不以测试代替 |
| 用户图章/组合可用性 | 记录真实反馈，不自动认可 |
| Tiled GUI | 按需试刷矩形、凸凹角、细路、分支、洞口、擦除和变体；没做则未验证 |
| 引擎、碰撞、导航 | 默认未验证；另行明确请求才进入 |

GUI 验证使用宿主实际支持的接口，保护已有编辑，只撤销本次笔迹；不按固定次数撤销，也不自动覆盖用户地图。

## 格式边界

生产输出是有限正交地图、外部图片集合 TSX、CSV 图块层与原生尺寸图块对象；保留层级/像素偏移。原生 TSX 导入支持图集 margin/spacing、稀疏图片集合、Wang、图块概率和标准动画。

首版不渲染无限地图、等距/六角、压缩/base64 层、GID 变换标志、对象缩放/旋转、图层透明度和颜色键透明；遇到这些内容直接报错。TMX 输入用于提取素材引用，不是转换现有游戏地图布局。内嵌 tileset 会列为待导出项；请用 Tiled 导出外部 TSX 后再盘点。非 PNG 原图需要先显式无损导出。
