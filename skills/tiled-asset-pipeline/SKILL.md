# Tiled 素材与地形集整理

用户提供素材目录和输出位置后，完成环境检查、素材分析、描述、转换、核验和预览。所有素材使用本技能附带的同一个转换器，差异写入每套素材的 JSON 描述；不要为每套素材另写转换脚本，也不要仅提供操作建议就结束任务。

## 首次运行与依赖自动安装

1. 确认宿主能查看原图、读写本地文件并执行命令。缺少能力时说明具体缺项，不能假装已查看图片或已运行转换。
2. 将本文件所在目录视为 `<skill>`，不是用户当前工作目录。先读 [环境准备](references/environment.md)，运行 `scripts/pipeline.py doctor`。
3. 缺少依赖时，**主动安装并继续任务**：用现有 Python 运行 `doctor --install --workspace <任务工作目录>`；缺少合适的 Python 时，使用 `scripts/bootstrap.sh`（macOS/Linux）或 `scripts/bootstrap.ps1`（Windows）。脚本优先复用环境，必要时安装用户级 uv、Python 3.12 和独立虚拟环境中的固定版 Pillow。
4. 安装会访问官方发行源。执行前简要说明安装对象与位置，遵循宿主权限和用户离线要求。安装失败时读取错误并修复明确原因；权限或网络不可用时报告恢复命令，不无限重试、不伪装成功。
5. 安装后使用 doctor 返回的虚拟环境 Python；环境本已齐备时沿用刚才检测通过的解释器。不要向系统 Python 安装包；不要升级其他项目依赖。Tiled 为按需 GUI 工具，不是文件生成的前置条件；不默认安装或启动。

## 从请求到统一转换

- 读取工作区规则，检查已有差异，确定来源、输出和整理范围。源目录只读，输出必须在其外；原素材许可如实登记，本技能的 MIT 不改变素材许可。
- 运行 `inspect --source <来源目录> --output <盘点目录>`，实际查看生成的像素坐标图和来源说明。粉色刻度不是网格；已有 TSX/TMX 可提取原生图块、Wang 和时序。盘点草稿尚不可生产，复制到盘点目录外再维护。
- 读取 [素材流程](references/asset-workflow.md)，先确认原生网格，再按地图用途整理。整除、文件名和相近颜色都不能单独证明网格、连接或帧序。网格未决时比较候选叠图，必要时询问用户。
- 按 [描述格式](references/manifest.md) 编写 `manifest.json`，逐地形族登记可用规则、受限缺项或不适用证据。地图素材整理默认包含地形审计，不以用户未单独说“地形集”跳过。
- 首次需要格式实例时读取 [完整 Corner 示例](assets/examples/corner/manifest.json) 或 [受限 Edge 示例](assets/examples/edge/manifest.json)，不要复制其坐标到新素材。
- 元数据足够就直接复用；分析中有影响正确性的歧义才询问。新素材中的坐标、结构、规则和时长不得从历史素材继承。未核实部分留在 `pending`，不得清空字段以绕过验收。
- 运行 `build --manifest <描述> --source <来源> --output <成品>`，再运行相同参数的 `check`。转换器使用显式坐标和规则，支持 PNG 与外部 TSX 元数据；未支持格式须明确说明，不静默丢弃。
- 实际查看最终 `preview.png`、完整图章与组合局部、环境动画 APNG/状态接触表，按 [格式验收](references/format-validation.md) 核查。需要修改时修正描述并重建；不要直接改生成文件绕过检查。

## 核心判断

- 只整理范围内的地形、建筑、植被、设施和可摆放物件。人物/换装/动物角色/UI/物品栏图标默认列为排除项；不要整包盲收。混合图集按明确矩形区分用途。
- 完整单体是图章；组合须展示独立物件之间真实的连接、承接、遮挡或空间关系。散格、截图裁片和换色不算组合。完整图章记录尺寸、接地点、实体占地与层序。
- 按用途和结构归组，颜色/季节/轻微外观放入组内；横竖接口、立面/平面和实体/透明覆盖须区分。同一入口 TMX 按组分区，可用变体全部可见，不承诺目标编辑器不存在的自定义面板。
- 密集素材目录对象不设置非空 XML `name`；说明放在自定义属性 `名称`，分类使用图层/组名。交付前检查名称属性保留、目录对象没有画布名称标签；离线渲染不包含编辑器标签，不能据此声称 GUI 已验证。不要只改 Tiled 全局显示设置，也不要清除用户实际场景中有用途的对象名称。
- 使用真实 Corner/Edge/Mixed 规则，源素材缺项就明确受限，不能旋转、镜像、补绘或缩放来凑完整。颜色编号 0 不等于地图空 GID，支持连接集合必须显式登记。
- 主动查找环境动态和状态序列，保留完整画布、部件、配套阴影及透明终帧。未知速度标 `preview`，不得冒称原生时长；状态集合不串为循环动画。
- 源 PNG 无损，只读保存哈希。派生格保留原 RGBA，展示缩放不能改变成品像素。具体组合经验可从作者说明和用户提供案例研究，不依赖任何私有素材库。

## 维护与完成

`check` 只读、不修复、不刷新时间戳。生成器保护已有修改；发生冲突时保留用户文件，选择新成品目录，不用删除或修改输出登记强制覆盖。真实游戏场景另存，不将用户手改地图当作展示板重建目标。

交付入口 TMX、全部 TSX/PNG、来源和覆盖清单、中文说明、静态与动画预览。分别报告文件/像素/静态规则、视觉检查、GUI 和引擎验证。技术通过不能代替用户视觉认可，也不能声称地形刷已在编辑器试刷。

请用户审阅当前图章和组合的实际可用性，记录真实反馈；技术交付无需伪造批准或阻塞在额外审批系统。素材整理交付后不自动进入场景制作、引擎导入、碰撞或导航发布。用户明确要求 GUI 时才使用宿主支持的操作方式，在可恢复区域检查，不覆盖已有编辑。
